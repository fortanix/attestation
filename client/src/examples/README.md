# Examples

The examples in this directory are for a SEV-SNP and TDX attestation clients.

These are _NOT_ intended for production use, and any implementation in the examples
is not guaranteed to be functional with CCM SaaS/OnPrem instances and Node Agents.
Please do not use them for this purpose.

The examples are only presented to demonstrate the usage of
the [attestation](../../../attestation)
and [client](../..)
libraries to allow a client to connect to a Node Agent and obtain
an attestation/certificate.
